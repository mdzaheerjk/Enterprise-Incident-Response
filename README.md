# Enterprise-Incident-Response
Build an intelligent Enterprise Incident Response AI Copilot using LangGraph Self-RAG, OpenAI Pinecone, and FastAPI to investigate cloud incidents and recommend troubleshooting steps. Implement self-corrective retrieval, document relevance grading, query rewriting, hallucination checks, persistent conversation memory, and Tavily web-search fallback
